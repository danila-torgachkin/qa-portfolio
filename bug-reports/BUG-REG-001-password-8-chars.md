# Баг-репорт: пароль из 8 символов

| Поле | Значение |
| --- | --- |
| ID | BUG-REG-001 |
| Заголовок | Пароль из 8 символов отклоняется с ошибкой «Пароль слишком короткий» при регистрации в Chrome 130 |
| Окружение | Тестовый стенд, Chrome 130, Windows 11, версия сборки: v1.0 |
| Предусловия | Аккаунта Un1cal@mail.ru нет в системе, страница регистрации доступна. |
| Шаги | 1. Открыть страницу регистрации. 2. Ввести email - Un1cal@mail.ru. 3. Ввести пароль - Qwer123!. 4. Нажать «Регистрация» |
| Фактический результат | Регистрация не прошла. Поле пароля подчеркнулось красной линией, под полем ошибка «Пароль слишком короткий» |
| Ожидаемый результат | Аккаунт создан, открыт экран подтверждения почты. Основание: допущение «минимальная длина пароля 8 символов»; в требованиях не зафиксировано — вопрос аналитику. |
| Severity | Major — обход есть: пароль из 9+ символов принимается |
| Priority | High |
| Воспроизводимость | 3 из 3 |
| Вложения | Скриншоты до и после — в тикете BUG-REG-001 |
